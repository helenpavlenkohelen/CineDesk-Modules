# CineDeck 🎬

**CineDeck** is a responsive movie search application built with HTML, SCSS, and Vanilla JavaScript.

The application uses the OMDb API to search for movies and display detailed information.

## Features

- Search movies by title.
- View detailed movie information.
- Add and remove movies from favorites.
- Save favorites using Local Storage.
- Sort movies by title.
- Debounced search input.
- Responsive design.

## Technologies

- HTML5
- SCSS / CSS3
- JavaScript (ES6+)
- JavaScript Modules
- OMDb API
- Local Storage

## Project Structure

- `css/` — styles and SCSS files.
- `images/` — images and assets.
- `js/api/` — API requests.
- `js/features/` — application functionality.
- `js/ui/` — UI rendering.
- `js/utils/` — utility functions.

## Installation

1. Clone the repository.
2. Open the project in VS Code.
3. Configure your OMDb API key in `js/config.js`.
4. Run the project using Live Server.
